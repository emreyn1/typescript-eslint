# Contributing

- Prefer **small, focused** PRs; avoid new dependencies unless necessary.
- Run `python3 -c "compile(open('telegram_mirror.py').read(),'telegram_mirror.py','exec')"` before submitting (or your usual linter).
- Do not commit **API keys, phone numbers, or chat IDs** — placeholders only in `.env.example`.
- Update **README.md** when behavior or CLI changes.
