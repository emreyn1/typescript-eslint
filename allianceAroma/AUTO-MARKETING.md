# Genel Mimari

```
[SEN] → Haftalık 45 dk: kontrol + yönlendirme
  ↓
[FREELANCER] → Günlük iş: video üretim + paylaşım + etkileşim
  ↓
[OTOMASYON] → Bot + zamanlayıcı: Telegram, Twitter, Buffer
  ↓
[3 MARKA] → SMS Sitesi + Film Sitesi + No KYC Kart
```

**Senin rolün:** Yönetici. Freelancer'a ne yapacağını söylersin, o yapar. Sen üretime dokunmazsın.

| Seçenek | Detay |
|---------|-------|
| **Seçenek A: 1 freelancer, 3 marka** | Ucuz ama freelancer 3'ünün bağlantılı olduğunu bilir |

| Adım | Detay |
|------|-------|

| 2 | Twitter hesaplarını bağla (3 marka) |

| 4 | Buffer otomatik paylaşır |
| 5 | Freelancer sadece gelen yanıtlara cevap verir |

### Telegram Bot (otomatik mesaj)

```python
# Basit Telegram bot — zamanlanmış mesaj
# VPS'te cron job olarak çalışır

import requests
import json

BOT_TOKEN = "your_bot_token"
CHANNEL_ID = "@your_channel"

def send_message(text):
    url = f"https://api.telegram.org/bot{BOT_TOKEN}/sendMessage"
    data = {"chat_id": CHANNEL_ID, "text": text, "parse_mode": "HTML"}
    requests.post(url, data=data)

# Günün mesajı
messages = {
    "monday": "💡 Did you know?\n\nThe average person receives 40+ spam texts...",
    "tuesday": "📖 TUTORIAL: How to use [SiteAdı]...",
    # ... her gün için
}

import datetime
today = datetime.datetime.now().strftime("%A").lower()
if today in messages:
    send_message(messages[today])
```

**Cron job (VPS'te):**
```bash
# Her gün sabah 09:00'da çalıştır
0 9 * * * python3 /home/user/telegram_bot.py
```
